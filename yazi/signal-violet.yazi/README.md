# Signal Violet — Yazi flavor

Signalman ailesinin ucuncu paleti. Mod rozeti masaustu moru (#C57AD4),
sekme ve imlec sarisi (#F5C842). Kod onizlemesi `tmtheme.xml` ile,
Neovim ve VSCodium temasiyla ayni renklerde.

## Kurulum

```sh
cp -r yazi/signal-violet.yazi ~/.config/yazi/flavors/
```

`~/.config/yazi/theme.toml`:

```toml
[flavor]
dark = "signal-violet"
```
