# Nazarick — Yazi flavor

Signalman ailesinin dorduncu paleti. Mod rozeti masaustu altini (#E0B878),
kod onizlemesi `tmtheme.xml` ile Neovim ve VSCodium temasiyla ayni renklerde.

## Kurulum

```sh
cp -r yazi/nazarick.yazi ~/.config/yazi/flavors/
```

`~/.config/yazi/theme.toml`:

```toml
[flavor]
dark = "nazarick"
```
